# The Ledger — Stable Vertical Slice

This is the first executable web prototype of the Zone 4 redesign.

## Loop
1. Inspect three fictional gig offers.
2. Accept or decline.
3. Resolve gross income, direct cost, operating-cost proxy, opportunity cost, time, and reputation.
4. Review provenance.
5. Solve the optional ARG research clue.

## Stability rules
- Deterministic scenario data and seed.
- Fictional geography is separate from source geography.
- IRS/EIA references are calibration inputs, not claims about actual player expenses.
- Opportunity cost is the best eligible alternative available at acceptance.
- If no eligible alternative exists, opportunity cost is zero.
- ARG is optional and never required for the economic loop.
- No gambling, wagering, financial credentials, or transactions.
