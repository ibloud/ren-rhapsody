## First Movement scope
- One short experience with a beginning, meaningful action, and ending.
- One mechanic demonstrating the music-and-movement concept.
- Original or otherwise cleared placeholder audio, with its source and permitted use recorded.
- A tested iPad/browser route from Break This Build.
- Gameplay evidence, independent test reports, accessibility findings, and a clear next step.

The browser preview is the default Halloween delivery path. A one-zone UEFN prototype is conditional on confirmed development access and a working build. Neither a browser preview nor a private UEFN prototype constitutes a published Fortnite island.

Defer the five-zone production build, complex NPCs, rhythm mini-games, audio-reactive environments, protected recordings and artist participation without documented permission, Xbox adaptation, and new ecosystem integrations.

## Release acceptance
Release only when the chosen build completes end to end, blocking defects are resolved, audio use is documented, iPad access has been tested, independent completion is recorded, and the actual release URL and revision are verified. Record accessibility limitations plainly; automated checks do not establish accessibility acceptance.

If a playable preview does not pass these checks, publish a clearly labeled development showcase and test findings on October 31. Record that the playable target was missed; do not rename a blueprint as a game.

The full Fortnite path remains separate: actual UEFN build, applicable rights and platform checks, private testing, publication/moderation, and a real island code verified by an independent player. No artist endorsement or platform approval is implied.
