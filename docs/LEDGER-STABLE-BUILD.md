# The Ledger — Stable Build Record

**Build:** Vertical Slice v1
**Branch:** feat/ledger-stable-vertical-slice
**Purpose:** convert the Zone 4 design specification into a runnable, inspectable prototype.

## Implemented
- One fictional district.
- One vehicle model.
- Three gig offers.
- Offer inspection with accept/decline.
- Deterministic time and cash state.
- Direct-cost accounting.
- Operating-cost proxy.
- Opportunity-cost rule based on the best eligible alternative at acceptance.
- Net outcome and reputation consequence.
- Provenance disclosure.
- Optional ARG clue with a public-source research question and code.
- No gambling or wagering interaction.

## Verification checklist
- [x] Three jobs are selectable.
- [x] Accept and decline both terminate safely.
- [x] Net outcome is explainable from displayed inputs.
- [x] Opportunity cost is explicit.
- [x] Fictional and source geographies are distinct.
- [x] ARG is optional.
- [x] No financial credentials or transactions are requested.
- [x] No casino, roulette, slots, raffle, wager, or betting mechanic exists.
- [x] Source URLs are stored as provenance data rather than treated as permissions.
- [ ] UEFN implementation remains a separate production task.

This build is a prototype reference implementation, not financial advice and not a representation of any specific gig platform, trip, city, or third-party endorsement.
